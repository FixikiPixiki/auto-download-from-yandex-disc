## Что делает
Автоматически проходит по всем файлам в открытой папке и запускает скачивание каждого. Работает из консоли браузера — без расширений и установки.

- 🚀 **Автопрокрутка** — подгружает весь список
- 🔍 **Проверка по названию файла** — учитывает обрезку `…`, NBSP, юникод
- 🔢 **Проверка по количеству объектов** в открытом окне
- 🔁 **Повтор при неудаче** — до 3 попыток
- 📊 **Отчёт в конце**

## Запуск
1. **Разрешите множественные загрузки в браузере**
2. **Откройте нужную папку** на Яндекс.Диске и убедитесь, что файлы видны в листинге.
3. **Откройте консоль браузера**
Нажмите **F12** (или `Ctrl + Shift + J` / `Cmd + Option + J` на macOS) → перейдите на вкладку **Console**.
4. **Вставьте код скрипта и нажмите Enter**
Ничего устанавливать не нужно — это простой скрипт, который выполняется прямо в браузере. Никаких расширений, userscript-менеджеров и настроек.
5. **Смотрите результат в консоли**
Скрипт сам прокрутит страницу, соберёт список файлов, запустит скачивание каждого и в конце выведет отчёт прямо в окно консоли:
